# RSI 工具风险 4B 扩量专项

本目录记录第七轮4B扩量训练。正式冻结数据位于 `dataset/`，候选数据和分层独立模型复核留档在本目录；`source-snapshot/`保存训练与审核代码，`trial-007/`保存q4训练、独立重载、同输入评估、服务恢复和哈希证据。

训练集累计10,000条（5,000需复核、5,000正常），新测试集1,200条（600/600）。其中新增数据由规则生成；238条代表样本经独立模型复核一致，人工金标为0。所有shell命令仅作为数据文本。

实验按 [实验预注册](实验预注册.md) 的固定0.5阈值门槛验收。训练结果是研究试验，不是生产工具审批模型。
