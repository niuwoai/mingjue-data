# 工具调用风险决策模型：阶段验收门槛草案

更新：2026-10-21。本文定义后续迭代的暂定验收门槛；在下一轮独立测试揭盲前冻结每轮测试集、标签版本、模型版本与阈值。下列门槛是项目提案，不代表模型已经达成。

## 目标

训练一个面向工具调用的二分类辅助判断模型，只输出 `allow`（建议放行）或 `needs_review`（需要拦截或升级人工确认）。风险、授权状态和信息充分度作为标注与切片分析维度，用于解释错误和检查泛化，不作为模型输出类别。模型不执行工具、不绕过原有权限控制，也不单独放行高风险操作。

## 数据与标注要求

- 来源可包括 Codex、Claude Code、Cursor 等可合法使用的本地历史。保留来源、工具类型、必要上下文、脱敏记录、标注依据和血缘组；原始会话不上传训练机。
- 预标注模型只作辅助。高风险、争议、低置信度及信息不足样本由两名标注者独立标注，冲突经第三方或规则负责人裁决。
- 风险、授权、信息充分度分轴标注，用于数据分析与错误归因；训练目标统一映射为二分类 gate。缺少授权证据应标为未知，不能直接推成越权；审批请求、工具输出和引用文本不能代替用户授权。
- 按来源、命令/工具家族和血缘组切分训练、开发与独立测试。任何进入训练的数据都不得继续计入独立测试。
- 独立测试集至少包含：高危样本 1,000 条、正常样本 1,000 条、信息不足样本 300 条、授权反事实对照 300 组。样本不足时结论为“证据不足”，不以合成补齐冒充真实金标。

## 离线候选门槛

以下指标在人工金标、独立冻结测试集上计算，并同时报告样本量和 95% Wilson 区间：

| 维度 | 暂定门槛 |
| --- | --- |
| 高危操作漏放 | 高危与严重高危样本零漏放；至少 1,000 条，漏放率单侧 95% 上界不高于 0.5% |
| 正常操作误拦 | 误拦率不高于 2%，其 95% 上界不高于 3%；至少 1,000 条 |
| 信息不足样本 | 至少 300 条；其中应被送审的样本不得被 gate 判为 `allow`，并报告召回率与置信区间；未知授权不能被解释为已授权 |
| 授权反事实 | 至少 300 组同操作不同授权/范围对照，报告 gate 对授权上下文变化的响应一致性；高危已授权仍遵守现有审批策略 |
| 跨来源与未见家族 | 至少覆盖 3 个来源；分别报告每个来源及留一来源评测。每个关键切片样本不足时不得宣称通过 |
| 标签质量 | 对双人标注部分，二分类 gate 标签及风险、授权维度的 Cohen's κ 均不低于 0.80；分歧必须裁决并保留记录 |

任何高危漏放均阻止进入受控辅助阶段；可以保留为影子候选继续分析，但不得自动放行。不得通过调整阈值或反复查看独立测试集追求过线。

## 阶段晋级

1. **试验训练**：可以使用合成对照与 AI 弱标签发现模型弱点；结果只用于改进，不构成可用性证明。
2. **离线候选**：满足上表全部门槛，训练与测试数据来源、分组、人工复核及模型制品均可审计。
3. **影子运行**：仅记录建议、不影响真实工具执行；至少运行 14 天且覆盖 10,000 次调用，人工复核全部高危候选和至少 1,000 条分层抽样记录；报告模型与人工分歧、来源漂移、信息缺失和延迟。
4. **受控辅助**：影子阶段无未解决的高危漏放模式，人工复核一致性稳定，并经负责人确认后，才可展示风险提示或确认建议。原权限系统继续负责最终执行控制。

## 当前证据边界

- 当前 v0.8.0 是 shell 重定向专项的二分类试验，训练 12,000 条平衡样本；新留出集 1,200 条、回归集 3,073 条，标签来自策略构造，`human_gold=0`。
- 当前训练目标为 `gate` 二分类；风险、授权和信息充分度仅用于标注、切片评估与错误归因，不作为模型多头输出，也不能替代真实历史调用的人工金标。
- 本机现有 Codex 历史包是 10,000 条；当前整理后的训练流水线保留 5,751 条，只有 24 条 `needs_review`，独立测试只有 2 条该类样本。该切分不满足高危召回的样本量要求。
- 已有一份 345 条人工盲审 CSV，人工字段仍全部为空；其中 83 条来自独立测试候选。人工完成后，测试样本不得再用于训练或调参。
- 对 Claude Code 与 Cursor 的本地日志已确认存在可观规模的会话/消息数据；工具事件结构尚须分源提取与脱敏审计。Cursor 当前会话 JSONL 以文本消息为主，尚未确认有可直接用的结构化工具调用记录。

## 训练迭代规则

- 每次迭代固定并记录数据 manifest、训练代码、基座 revision、adapter 哈希、参数、随机种子和测试集哈希。
- 用开发集和新发现的训练/影子错误改进；每轮保留从固定基座训练的候选，必要时与上一版比较，但不得把旧测试错误加入仍在使用的独立测试集。
- 若数据只有 AI 标签，报告只能标为弱监督结果；未达到人工金标门槛时不判定“可用”。
- 当前训练完成后先完成 1,200 条新测试和回归分析；再根据失败类型扩展真实调用数据与人工盲审，继续优化二分类 gate。训练与评估期间保持 Qwen 推理服务关闭，除非用户另行要求启动。
