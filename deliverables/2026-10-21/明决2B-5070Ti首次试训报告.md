# 明决 2B：RTX 5070 Ti 首次微调验证

日期：2026-10-21。脚本版本：0.1.0。通过 QTerm 操作 q4，完成一次实际 GPU 微调、保存、新进程重载和优化器续训。

## 结论与范围

RTX 5070 Ti 16GB 已跑通明决 2B 文本 BF16＋LoRA。32 次参数更新平均每步约 0.479 秒，训练进程峰值 reserved 显存约 5.01 GiB。模型可见完整输入长度为 244～253 token。这个结论只覆盖本次短输入、microbatch 1、rank 8 配置，不代表 1,024/2,048 token 或完整业务训练的吞吐与显存。

本轮使用 8 个独立编写的模板构造 32 条合成工具风险记录，包含正常、危险、越权、信息不足四类。没有使用待人工标注的历史记录，也没有执行样本中的命令。样本拟合改善只证明链路能够学习，不能证明业务准确率或泛化能力。

## 训练方法

- 使用上游 `src.inputs.schema.compile_row` 和检查点原有 chat template、`<decision>` 标记。
- 输入只保留决策占位符，监督目标在标记前一位置预测；完整词表交叉熵训练，推理时才对合法候选归一化。
- 只对实际语言骨干中存在的 Linear 模块加 LoRA，rank 8、alpha 16、dropout 0.05，AdamW 学习率 5e-5。
- 可训练参数 8,409,600；没有把视觉模块或 LM head 纳入 LoRA 覆盖。
- microbatch 1，未做梯度累积，开启激活重计算，关闭 KV cache。32 个优化器步覆盖全部 32 条合成样本一次。
- 审计 20 条记录的标记、监督位置与目标 token；一条记录的手工决策位置损失与 HF 标准 causal label-shift 损失完全一致。

```bash
/home/ml-data/rsi-smoke/venv/bin/python /home/ml-data/rsi-smoke/smoke.py train \
  --model /home/ml-data/rsi-smoke/model-2b \
  --upstream /home/ml-data/rsi-smoke/upstream \
  --run /home/ml-data/rsi-smoke/runs/fit-new --steps 32
```

使用相同参数把 `train` 替换成 `verify` 可在新进程验证已保存适配器；替换成 `resume` 可加载优化器及随机状态完成下一步。实际执行时会检查基座权重 SHA256，业务训练尚需独立数据构建、分组切分和质量验收。
