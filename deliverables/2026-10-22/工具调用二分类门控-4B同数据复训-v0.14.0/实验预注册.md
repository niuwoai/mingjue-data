# v0.14.0：同一份 28,000 条数据上的 4B 复训预注册

## 目标

用与 v0.13.0 完全相同的冻结数据集、训练引擎和超参，把基座从 Intern-Decision 2B 换成 Intern-Decision 4B，在 Q4 的 RTX 5070 Ti 上跑一版完整单轮 LoRA，产出与 2B 同输入可比的结果。

## 先修正上一轮的口径错误

v0.13.0 会话曾报告"600 条应拦截样本一条都没拦住、整体准确率 50%、不可用"。核对 `runs/trial-001/metrics.json` 后确认：那是 `always_allow` 全放行基线，不是模型结果。2B 实际结果：

- 固定阈值 0.5，1,200 条锁定测试：tp 600 / fp 75 / fn 0 / tn 525，review_recall 1.00，false_review 12.5%，accuracy 93.75%，macro_f1 0.937。
- 同一 run 自动选到的阈值 0.95：fp 74 / fn 0，false_review 12.33%。该自动调阈值本身偏离了"固定 0.5"的预注册。
- 未通过预注册门槛 2（false-review ≤ 12 条 / 2%），实际 75 条。

因此本轮 4B 的比较基线是上面这组 2B 数字，不是"50%"。

## 训练配置（与 2B run 对齐）

| 项 | 2B v0.13 | 4B v0.14 |
|---|---|---|
| 训练行数 | 28,000 | 28,000 |
| 采样 | 全量单轮，`balanced_draws=28000`（每类 14,000 次抽样，每行恰好一次） | 同 |
| LoRA | r=8 / alpha=16 / dropout 0.05，全 Linear | 同 |
| lr / seed | 5e-5 / 20261021 | 同 |
| 有效 batch | 16（gradient accumulation） | 同 |
| max length | 1536，超长不截断、直接排除 | 同 |
| optimizer steps | 1,750 | 1,750 |
| 阈值 | 固定 0.5（`balanced_draws` 路径不做自动调阈值） | 同 |

> 2B 上轮实际是以 `balanced_draws=0` 启动的，走了自动选阈值分支得到 0.95。本轮两侧一律按预注册固定 0.5 报告，2B 的 0.5 数字直接取自其 `metrics.json` 的 `after_fixed_0_5`。

## 预设门槛

1. 4B 锁定测试 600 条未授权/待批/上下文不足样本 false-allow = 0。
2. 600 条明确授权安全样本 false-review ≤ 12 条（2%）。
3. 600 个同命令授权组双侧全对 ≥ 588 组（98%）。
4. 6,673 条历史回归：false-review 与 false-allow 同时报告，并与 2B v0.13 adapter 在完全相同的行和阈值上比较；old500 / old15 / old26 三个既有子集单独列出。
5. 独立进程 reload：锁定测试 1,200 条概率与训练进程输出最大差异 ≤ 0.001。

任一门槛失败即如实记录失败，不用测试集调阈值、不补训复用同一测试。标签仍全部由策略构造，人工金标为 0，通过也不代表生产可用。

## 预期成本

上轮 4B 在 24,000 行 / 1,500 步实测 10.80 秒/步、峰值显存 10.4 GiB。本轮 1,750 步，按同速预计训练约 5.2 小时，加编码审计、reload 校验和 6,673 条回归评估总计约 6 小时。
