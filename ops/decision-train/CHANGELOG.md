# 变更记录

## [0.18.0-rc2] - 2026-10-22

### Added
- 登记 28,000 条定向 shell 授权对照训练集的独立实验 manifest；训练入口继续校验冻结拆分哈希。

## [0.18.0-rc1] - 2026-10-22

### Fixed
- 新增授权对照锁定测试集的盲审包生成器，使用不含标签的哈希 ID，并将答案映射单独限权保存。
- 人工复核按锁定测试集抽样并保留同命令授权对照，避免训练样本 ID 暴露预设标签。

## [0.18.0] - 2026-10-22

### Added
- 新增授权与文件写入对照试验的预注册门槛，并在4B评测中加入透明的保守规则基线。
- 保持阈值固定为0.5；测试集、历史回归集及人工金标状态分别报告。

## [0.17.0] - 2026-10-22

- 新增 24,000 条二分类门控训练版本，针对未授权写入、待批权限升级与安全临时文件授权建立同命令对照。
- 冻结 Python pathlib 与 install 两种新写入结构的 1,200 条独立候选测试，阈值固定为 0.5，并把上一轮测试转入回归集。
- 保留盲化人工复核队列；人工金标仍为0，合成结果不授予真实流量或自动审批资格。
- 训练 manifest 白名单登记 v0.12 实验。

## [0.16.0] - 2026-10-22

- 新增独立测试盲审结果导入校验，核对盲 ID、冻结输入、标签取值、证据与标注者。
- 人工标签只生成独立 human-gold 子集，不改写训练集或冻结测试；与策略构造标签的分歧单独记录，仍不授予生产资格。

## [0.15.0] - 2026-10-22

- 新增从未见家族锁定测试集盲抽200条人工复核样本的流程，按100组成对抽样并隐藏预设标签。
- 独立保存盲审ID映射和冻结标签并限制本地文件权限，人工结果可用于独立金标对比而不污染训练集。

## [0.14.0] - 2026-10-22

- 新增危险命令字面展示与实际子进程执行的成对二分类样本，训练累计扩至20000条。
- 冻结 Ruby、Node.js、Perl 三类未见包装家族的1200条独立测试，并把上一轮已观察测试转入回归集。
- 生成200条不含预设标签的人工复核队列；人工金标仍为0，训练结果不具备生产资格。
- 训练清单新增 v0.11 实验白名单，阈值继续固定为0.5。
- 评估器兼容 regression 哈希的旧/新清单布局，避免模型训练完成后因元数据路径差异中断评估。

## [0.13.0] - 2026-10-22

- 新增历史工具调用盲审队列生成器：排除所有已知实验数据集中的会话/命令重叠，限制单会话样本数，脱敏后仅导出人工标注字段。
- 输出抽样审计和权限受限文件，报告重叠排除、脱敏统计及人工金标仍为空的状态。

## [0.12.0] - 2026-10-22

- 修正盲化人工复核表行列数不一致问题，并增加表头/行宽一致性断言，避免后续标注导入错列。

## [0.11.0] - 2026-10-22

- 训练入口显式接纳 v0.10.0 的 16000 条命令族扩展实验 manifest，并保留冻结哈希、人类复核计数和无覆盖校验。
- 固定记录训练引擎版本，便于区分数据包版本与模型训练代码版本。

## [0.10.0] - 2026-10-22

- 新增 sfdisk、busybox、python3、env 和 cat 命令族的二分类门控对照数据生成器，累计训练集扩至16000条，并冻结1200条新命令包装测试。
- 新建200条盲化人工复核表，显式保留人工金标为0；旧测试候选转为已观察回归，不允许据合成满分晋级。
- 新增训练/测试家族隔离、同命令授权对照、数据哈希和人工复核空字段验证。

## [0.9.1] - 2026-10-21

- 训练入口支持显式冻结训练行数，为 12000 条平衡样本迭代增加审计校验。

## [0.9.0] - 2026-10-21

- 新增238条分层独立模型预标注复核，复核结果与规则标签一致；人工金标仍为0，所有新增命令仅作数据文本。
- 新增q4 4B完整训练、独立重载及同一新测试上对比基座/上轮4B的流程，固定阈值0.5并恢复原推理服务。

## [0.8.0] - 2026-10-21

- 代表情境经独立模型复核后才冻结数据，保留弱监督与新组合测试边界及服务恢复证据。

## [0.5.0] - 2026-10-21
