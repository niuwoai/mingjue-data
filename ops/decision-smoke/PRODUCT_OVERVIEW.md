# 明决 2B 单卡训练冒烟

版本：0.1.0。仅验证工程链路，尚不能证明业务泛化效果。

使用固定版本 `internlm/Intern-Decision-2B`，BF16 基座加 rank 8 LoRA，只覆盖实际语言骨干中的 Linear 模块；冻结视觉路径与其他基座参数。复用上游 schema 编译器，在 `<decision>` 前一位置读取 logits，按完整词表交叉熵训练。输入中保留决策占位符，目标答案仅进入损失。

数据为 8 个独立编写的工具风险模板构造的 32 条合成记录，仅用于小样本拟合，不是人工标注业务数据，也不构成独立测试集。所有命令都只作为文本进入模型，绝不执行。

入口：`smoke.py train|verify|resume --model 路径 --upstream 官方源码路径 --run 实验目录`。`train` 要求全新实验目录；`verify` 新进程比较保存前后的概率；`resume` 加载优化器及 CPU/CUDA 随机状态，验证能够继续完成一步更新，保留原检查点不覆盖。

输出包含权重 SHA256、实际 LoRA 覆盖模块、数据、逐步损失/梯度/耗时、峰值显存、训练参数数量、适配器变化、新进程重载和续训记录。基座冻结审计由 trainable 参数名单检查与 embedding 样本不变检查构成，不等于逐个冻结参数的全量哈希比较。

验收：前向反向无异常、有限非零梯度、适配器确实更新、损失变化如实记录、新进程概率最大绝对差不超过 1e-3、加载优化器与 RNG 后完成下一步。合成样本损失降低不代表真实业务验收通过。当前没有 API，脚本输出及指标文件暴露版本。
